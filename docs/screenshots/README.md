# Screenshots

Add PNG (or WebP) files here before making the repository public. The root README links these paths; broken images until then are expected.

## Expected filenames

| File | Screen |
|------|--------|
| `01-login.png` | Login (email/password) |
| `02-feed.png` | Match feed (Upcoming / Live / Finished) |
| `03-prediction.png` | Prediction input + lock countdown |
| `04-ledger.png` | Payment ledger ("Já paguei") |

## Capture tips

- Prefer a consistent device frame (phone portrait).
- Use Portuguese UI as shipped.
- Avoid showing real friends’ emails or private group codes; use a throwaway account when possible.
